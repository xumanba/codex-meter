# CodexMeter · Windows

[返回首页](../README.md) · [开发源码](源码/README.md)

安装包与 Mac 完全分开。当前推荐 **v0.1.4**，支持 Windows 10/11、.NET Framework 4.7.2 或更高版本；需已有 Codex 登录。

| 版本 | 定位与主要区别 |
| --- | --- |
| [v0.1.4](版本/v0.1.4/README.md) | 当前版：时间轴延伸至今天，显示距上次重置已过多久，点击倒计时直达时间轴 |
| [v0.1.3](版本/v0.1.3/README.md) | 内置 CLI，近 7 天用量、模型偏好、重置历史；模块化重构 |
| [v0.1.2](版本/v0.1.2/README.md) | 经核验补发的内置 CLI 历史包；核心程序与 v0.1.3 相同，版本标识不同 |
| [v0.1.1](版本/v0.1.1/README.md) | 早期质量更新：单实例恢复、重置时间对齐、缓存时效判断、可选安装脚本 |
| [v0.1.0](版本/v0.1.0/README.md) | 首发 Windows 版：额度卡片、网速、托盘、主题及左右贴边 |

以上 5 个版本均可进入对应文件夹独立下载。v0.1.0 / v0.1.1 未内置 CLI，需要另装并登录 Win-CodexBar；v0.1.2 / v0.1.3 / v0.1.4 不需要额外安装。

当前源码在“源码”文件夹；历史源码通过各版本页的 Git tag 获取。目录调整不改动已有设置、安装路径、自启动项或正在运行的程序，也不修改已发布安装包。
