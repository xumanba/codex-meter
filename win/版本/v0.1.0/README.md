# Windows v0.1.0

[Windows 所有版本](../../README.md) · [当前维护源码](../../源码/README.md)

首发 Windows 版本，提供额度卡片、实时上传 / 下载速度、最小化到托盘、主题和左右贴边。与 Mac 首发包共用一个 Release，但安装包彼此独立。

## 安装包

- [下载 Windows ZIP](https://github.com/xumanba/codex-meter/releases/download/v0.1.0/Codex-Meter-Windows-portable-v0.1.0.zip)
- [SHA-256 校验文件](https://github.com/xumanba/codex-meter/releases/download/v0.1.0/Codex-Meter-Windows-portable-v0.1.0.zip.sha256)
- [原 Release 页面](https://github.com/xumanba/codex-meter/releases/tag/v0.1.0)

SHA-256：

```text
067c0d3569440b2693e08db7be3b74626b4046c41e83ba7294592363a2d5fae2
```

完整解压后运行 `CodexMeter.exe`。支持 Windows 10/11；此历史包未内置 CLI，需要预先安装并登录 Win-CodexBar，建议新用户选择 v0.1.4。程序未进行 Authenticode 签名，请核实来源后再运行。
