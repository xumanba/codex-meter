# Windows v0.1.1

[Windows 所有版本](../../README.md) · [当前维护源码](../../源码/README.md)

早期质量更新。相比 v0.1.0 改进单实例恢复、置顶开关、重置时间对齐、悬停提示、旧缓存时效判断及可选安装脚本。尚不包含新版本的周用量展开面板和重置历史时间轴。

## 安装包

- [下载 Windows ZIP](https://github.com/xumanba/codex-meter/releases/download/v0.1.1/Codex-Meter-Windows-portable-v0.1.1.zip)
- [SHA-256 校验文件](https://github.com/xumanba/codex-meter/releases/download/v0.1.1/Codex-Meter-Windows-portable-v0.1.1.zip.sha256)
- [原 Release 页面](https://github.com/xumanba/codex-meter/releases/tag/v0.1.1)

SHA-256：

```text
ce4119c68564c18d92bebef28b9ec361e8e5840f0a4a3fc01cd298d0f2fb58ee
```

完整解压后运行 `CodexMeter.exe`。支持 Windows 10/11；此历史包未内置 CLI，需要预先安装并登录 Win-CodexBar，建议新用户选择 v0.1.4。程序未进行 Authenticode 签名，请核实来源后再运行。升级前从托盘退出旧程序；可选安装脚本见 ZIP 内说明。
