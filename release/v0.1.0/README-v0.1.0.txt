Codex Meter v0.1.0 - Windows and macOS
======================================

中文
----

Codex Meter v0.1.0 是第一个统一的 Windows 与 macOS 正式版本。
请根据系统分别下载，不要交叉安装：

- Windows 10/11：Codex-Meter-Windows-portable-v0.1.0.zip
  解压后进入“Codex Meter Windows v0.1.0”文件夹，运行 CodexMeter.exe。
  Windows 版需要预先安装并登录 Win-CodexBar。Windows 独有功能包括
  实时上传/下载网速以及最小化到系统托盘。

- macOS 14+：Codex-Meter-macos-universal-0.1.0.zip
  解压后把 Codex Meter.app 移到“应用程序”。该通用包支持 Apple silicon
  和 Intel Mac，并保持原 v0.1.0 Mac 安装包及功能不变。

两个平台均支持 Codex 剩余额度、重置时间、节奏信息、浅色/深色主题和
左右贴边隐藏。请使用 SHA256SUMS-v0.1.0.txt 核对下载文件。

Windows 程序未进行 Authenticode 签名；Mac 程序为 ad-hoc 签名且未经过
Apple 公证，因此首次运行可能需要手动确认。

English
-------

Codex Meter v0.1.0 is the first unified stable release for Windows and macOS.
Download the archive for your operating system:

- Windows 10/11: Codex-Meter-Windows-portable-v0.1.0.zip
  Extract it, open “Codex Meter Windows v0.1.0”, and run CodexMeter.exe.
  Win-CodexBar must already be installed and signed in. Live network speed and
  notification-area minimize/restore are Windows-only features.

- macOS 14+: Codex-Meter-macos-universal-0.1.0.zip
  Move Codex Meter.app to Applications after extracting it. The existing
  universal Apple silicon/Intel v0.1.0 package and its functionality are unchanged.

Both platforms show remaining Codex allowance, reset timing, pace information,
dark/light themes, and left/right edge docking. Verify downloads with
SHA256SUMS-v0.1.0.txt.

The Windows binary is not Authenticode-signed. The Mac application is ad-hoc
signed and not Apple-notarized, so first-run confirmation may be required.
