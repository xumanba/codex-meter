Codex Meter Windows v0.1.1 - download guide
================================================

中文
----

这是 Windows 专属质量更新。请下载：

  Codex-Meter-Windows-portable-v0.1.1.zip

解压后进入“Codex Meter Windows v0.1.1”文件夹，运行 CodexMeter.exe。
Windows 版需要预先安装并登录 Win-CodexBar。ZIP 已包含可选的当前用户
install.ps1 和 uninstall.ps1；使用脚本升级前请先从托盘退出旧程序。

相较 Windows v0.1.0，v0.1.1 增加或改进了实时上下行网速、托盘最小化、
单实例恢复、F5 同步、统一并对齐的额度重置倒计时、悬停详情、旧数据过期
识别、错误脱敏以及安装包验证。

macOS 程序不在此 ZIP 中。Mac 用户继续单独下载且仅使用：

  Codex-Meter-macos-universal-0.1.0.zip

Windows v0.1.1 没有修改 macOS v0.1.0 的程序、功能或安装包。

English
-------

This is a Windows-only quality update. Download:

  Codex-Meter-Windows-portable-v0.1.1.zip

Extract it, open “Codex Meter Windows v0.1.1”, and run CodexMeter.exe.
Win-CodexBar must already be installed and signed in. The ZIP includes optional
per-user install.ps1 and uninstall.ps1 scripts. Exit an installed copy from the
tray before upgrading with the script.

Compared with Windows v0.1.0, v0.1.1 adds or improves live aggregate network
speed, tray minimize/restore, single-instance restore, F5 refresh, consistent
and aligned reset countdowns, hover details, stale-provider-data detection,
error sanitization, and package validation.

No macOS application is included in this ZIP. Mac users should separately
download and continue using:

  Codex-Meter-macos-universal-0.1.0.zip

Windows v0.1.1 does not modify the macOS v0.1.0 application, features, or
installation archive.
