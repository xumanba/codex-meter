# macOS v0.2.0

[Mac 所有版本](../../README.md) · [当前维护源码](../../源码/README.md)

当前 Mac 发布版本，软件名为 CodexMeter，提供周用量、近 7 天每日统计与模型偏好。支持 macOS 14+、Apple silicon / Intel，安装包内包含 CodexBar CLI。
